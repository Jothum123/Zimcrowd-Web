# 📱 Zimbabwe Phone Number Format Guide

## ✅ Correct Format

### **Mobile Money Payments (EcoCash, OneMoney, InnBucks)**

**Format:** `+2637XXXXXXXX`

Where:
- `+263` = Zimbabwe country code
- `7` = Mobile prefix
- `XXXXXXXX` = 8 digits (first digit 1-9, rest 0-9)

---

## 📋 Examples

### **✅ CORRECT:**
```
+263771234567  ← EcoCash (Econet)
+263781234567  ← OneMoney (NetOne)
+263773456789  ← Valid Econet
+263786543210  ← Valid NetOne
+263779876543  ← Valid mobile
```

### **❌ INCORRECT:**
```
263771234567   ← Missing + sign
0771234567     ← Local format (not accepted)
+263 77 123 4567  ← Has spaces
+26377 123 4567   ← Has spaces
077-123-4567   ← Has dashes
```

---

## 🏢 Network Prefixes

### **Mobile Networks:**
- **Econet:** `+26377...` and `+26378...`
- **NetOne:** `+26371...`
- **Telecel:** `+26373...`

### **Mobile Money Services:**
- **EcoCash (Econet's service):** `+26377...` or `+26378...` ✅
- **OneMoney (NetOne's service):** `+26371...` ✅


### **Step 3: Add your 7-digit number**

## 💡 Tips

### **If you have a local number:**
```
Local:  0771234567
Convert to: +263771234567
```

**Conversion:**
1. Remove the leading `0`
2. Add `+263` at the start

### **Examples:**
```
0771234567  →  +263771234567
0781234567  →  +263781234567
0733456789  →  +263733456789
```

## 🔍 Validation

The system will check:
- ✅ Starts with `+263`
- ✅ Followed by `7`
- ✅ Next digit is 1-9
- ✅ Total of 12 characters
- ✅ No spaces or special characters

---

## 🚨 Common Errors

### **Error: "Invalid Zimbabwe phone number format"**

**Cause:** Number doesn't match the required format

**Solution:**
1. Check you have `+` at the start
2. Verify country code is `263`
3. Ensure mobile prefix is `7X`
4. Remove any spaces or dashes
5. Make sure total length is 12 characters

---

### **Error: "EcoCash requires an Econet number"**

**Cause:** You selected EcoCash but entered a non-Econet number

**Solution:**
- For EcoCash: Use Econet number `+26377...` or `+26378...`
- For OneMoney: Use NetOne number `+26371...`
- Make sure you select the payment method that matches your mobile network
